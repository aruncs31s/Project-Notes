# Project Overview

## GCEK LMS Backend

Learning Management System API for GCEK educational platform.

## Features

- [x] User Authentication (JWT)
- [x] Course Management
- [x] Module System (video/chapter/pdf)
- [x] File Assignments
- [x] Coding Assignments
- [x] Code Execution Sandbox
- [x] Course Reviews & Likes
- [x] Chat System (WebSocket)
- [x] Notifications
- [x] Certificates
- [x] Leaderboard
- [x] Swagger Documentation
