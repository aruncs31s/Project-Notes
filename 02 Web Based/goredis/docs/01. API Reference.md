# 01. API Reference

This document provides a detailed API specification of the `goredis` library packages, interfaces, and methods.

---

## 🏛️ Core Struct: `Client`

The `Client` struct represents the primary cache controller interface wrapping the Redis client.

```go
type Client struct {
	rdb       *redis.Client
	codec     Codec
	namespace string
	metrics   Metrics
	sf        singleflight.Group
}
```

### Constructor: `New`
```go
func New(rdb *redis.Client, opts ...Option) *Client
```
Initializes a new `Client` with standard defaults (JSON codec, `goredis` namespace, `noopMetrics` telemetry).

---

## ⚙️ Functional Options

Options can be supplied to `New` to customize the client behavior:

### `WithCodec`
```go
func WithCodec(codec Codec) Option
```
Overrides the default serialization/deserialization codec.

### `WithNamespace`
```go
func WithNamespace(ns string) Option
```
Prefixes all keys created by this client with `<namespace>:`. Prevents key collision in shared environments.

### `WithMetrics`
```go
func WithMetrics(m Metrics) Option
```
Injects a custom telemetry adapter for cache observability.

---

## 💾 Core Methods

### `CacheSet`
```go
func (c *Client) CacheSet(ctx context.Context, key string, value any, ttl time.Duration, tags ...string) error
```
Serializes and stores `value` under `key` with a specified `ttl` expiration. It atomically links the key to the provided `tags` (using Redis transaction pipeline `TxPipeline`).

### `CacheGet`
```go
func (c *Client) CacheGet(ctx context.Context, key string, dest any) (bool, error)
```
Retrieves the serialized value under `key`, deserializes it into `dest`, and returns `true` if found, or `false` on a cache miss.

### `CacheGetOrFetch` (Global Function)
```go
func CacheGetOrFetch[T any](ctx context.Context, c *Client, key string, ttl time.Duration, fetch func() (T, error), tags ...string) (T, error)
```
Wraps the cache-aside pattern. Attempts to load from the cache. On miss, executes `fetch`, writes the result back to the cache with `ttl` and optional `tags`, and returns the value.

---

## 🏷️ Invalidation Methods

### `InvalidateByTags`
```go
func (c *Client) InvalidateByTags(ctx context.Context, tags ...string) error
```
Clears all keys registered under the provided tags. It removes keys matching the tags and deletes the tracking tag sets themselves.

### `InvalidatePrefix`
```go
func (c *Client) InvalidatePrefix(ctx context.Context, prefix string) error
```
Invalidates all keys that start with `<namespace>:<prefix>`.

### `InvalidatePattern`
```go
func (c *Client) InvalidatePattern(ctx context.Context, pattern string) error
```
Invalidates keys matching a standard glob pattern (e.g. `user:*`).

---

## 🔌 Core Interfaces

### `Codec`
Used for custom serialization (e.g., Msgpack, Protobuf, Gob).
```go
type Codec interface {
	Marshal(v any) ([]byte, error)
	Unmarshal(data []byte, v any) error
}
```

### `Metrics`
Used for telemetry integrations.
```go
type Metrics interface {
	Hit(key string)
	Miss(key string)
	Set(key string)
	Invalidate(tags []string)
	FetchDuration(key string, d time.Duration)
}
```
