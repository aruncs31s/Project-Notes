# 01. Unit Testing

This guide shows how to write clean tests for your caching layer, including mocking telemetry and verifying Prometheus metrics programmatically.

---

## 🧪 Testing with Isolated Registries

When testing telemetry, you should avoid using the global `prometheus.DefaultRegisterer` because metrics can only be registered once. If multiple tests try to register the same metrics, they will panic.

Always initialize your Prometheus metrics adapter with a clean, isolated registry (`prometheus.NewRegistry()`) for each test run.

---

## 📝 Example: Verifying Metrics in a Unit Test

Below is a complete test showing how to verify that metrics like cache hits and misses increment as expected:

```go
package mytests

import (
	"strings"
	"testing"
	"time"

	"github.com/aruncs31s/goredis"
	goredisprom "github.com/aruncs31s/goredis/prometheus"
	"github.com/go-redis/redis/v8"
	"github.com/prometheus/client_golang/prometheus"
)

func TestCacheTelemetry(t *testing.T) {
	// 1. Create an isolated registry for the test
	reg := prometheus.NewRegistry()

	// 2. Initialize Prometheus metrics with the registry
	m, err := goredisprom.New(goredisprom.Options{
		Namespace: "test",
		Subsystem: "cache",
		Registry:  reg,
		KeyMapper: func(key string) string {
			if strings.HasPrefix(key, "user:") {
				return "user"
			}
			return "other"
		},
	})
	if err != nil {
		t.Fatalf("Failed to initialize metrics: %v", err)
	}

	// 3. Record some mock cache operations
	m.Hit("user:123")
	m.Hit("user:456")
	m.Miss("product:999")
	m.Set("user:123")
	m.FetchDuration("user:123", 250*time.Millisecond)

	// 4. Gather metrics from the registry to verify values
	metricFamilies, err := reg.Gather()
	if err != nil {
		t.Fatalf("Gather failed: %v", err)
	}

	var userHits, otherMisses, userSets float64
	var fetchCount uint64
	var fetchSum float64

	for _, family := range metricFamilies {
		name := family.GetName()
		for _, metric := range family.GetMetric() {
			// Read metric labels
			var keyGroup string
			for _, label := range metric.GetLabel() {
				if label.GetName() == "key_group" {
					keyGroup = label.GetValue()
				}
			}

			// Validate values
			switch name {
			case "test_cache_goredis_cache_hits_total":
				if keyGroup == "user" {
					userHits = metric.GetCounter().GetValue()
				}
			case "test_cache_goredis_cache_misses_total":
				if keyGroup == "other" {
					otherMisses = metric.GetCounter().GetValue()
				}
			case "test_cache_goredis_cache_sets_total":
				if keyGroup == "user" {
					userSets = metric.GetCounter().GetValue()
				}
			case "test_cache_goredis_cache_fetch_duration_seconds":
				fetchCount = metric.GetHistogram().GetSampleCount()
				fetchSum = metric.GetHistogram().GetSampleSum()
			}
		}
	}

	// 5. Assert values
	if userHits != 2 {
		t.Errorf("Expected 2 user hits, got %f", userHits)
	}
	if otherMisses != 1 {
		t.Errorf("Expected 1 miss, got %f", otherMisses)
	}
	if userSets != 1 {
		t.Errorf("Expected 1 set, got %f", userSets)
	}
	if fetchCount != 1 {
		t.Errorf("Expected 1 fetch sample, got %d", fetchCount)
	}
	if fetchSum != 0.25 {
		t.Errorf("Expected fetch sum of 0.25s, got %fs", fetchSum)
	}
}
```

## 🏃 Commands to Run Tests

To run the unit tests in your repository:

```bash
# Run tests for the prometheus metrics package
go test -v ./prometheus/...

# Run all tests in the repository
go test -v ./...
```

> [!TIP]
> Use the `-v` flag to output verbose logs showing individual test success/failure details and execution times.
