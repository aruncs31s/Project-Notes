# Implementation Plan: Assign Devices to Locations

Implement a complete workflow to assign, reassign, and unassign devices to/from locations, accessible via both the **Device Edit Modal** (in `SmartDeviceDetail` / `DeviceDetail` / `MicrocontrollerDetail`) and the **Location Devices Page** (`/locations/:id/devices`).

---

## User Review Required

> [!IMPORTANT]
> - **Multi-Type Location Devices**: Currently, the backend `GetDevicesByLocationID` query was filtering only devices with `HardwareTypeSolar`. We will remove this restriction so that all device types (Solar Chargers, Microcontrollers, Single Board Computers, Sensors) assigned to a location will properly appear on `/locations/:id/devices`.
> - **Unassign Capability**: Devices can also be unassigned (set to "No Location / Unassigned") from either the device edit modal or directly from the location devices list with a remove/unassign button.
